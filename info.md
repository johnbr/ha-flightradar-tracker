## Flight Map Card

An interactive map of the aircraft overhead — tap one and read its full detail below the map.

- Pan, pinch and zoom freely; a data tick never snaps the view back.
- Rotated aircraft markers that move rather than blink, with tracks.
- Detail panel below the map: photo, airline, route with airport-local times, progress, and
  live telemetry.
- Draws with Home Assistant's own bundled Leaflet — no API key, no CDN.
- Reads one attribute on the Flightradar24 integration's area sensor. No backend setup.
